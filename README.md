# Online Placement Portal — Frontend

A professional, modern, and interactive student-facing frontend prototype for an Online Placement Portal. This interface is designed to provide a seamless experience for students looking for jobs, tracking applications, and managing their profiles.

## ✨ Features

- **Interactive Dashboard:** Overview of applications, upcoming interviews, and recent job postings.
- **Job Board:** Browse, filter, and apply for open positions.
- **Application Tracking:** Monitor the status of job applications in real-time.
- **Interview Management:** Keep track of scheduled technical and HR rounds.
- **Resume Builder/Uploader:** Manage professional details and documents.
- **Notifications System:** Real-time updates on job alerts and application statuses.
- **Profile & Settings:** Customizable user preferences and profile details.
- **Modern UI/UX:** Responsive design with smooth animations and intuitive navigation.

## 🛠️ Tech Stack

- **Framework:** [React 18](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

Follow these steps to set up and run the project locally.

### Prerequisites

Ensure you have the following installed on your machine:
- **Node.js** (version 18 or higher)
- **npm** (comes with Node.js) or **yarn** / **pnpm**

### Installation & Setup

1. **Extract/Clone the Project:**
   If you received a ZIP file, extract it to a desired location.

2. **Navigate to the Project Directory:**
   Open a terminal and go to the project folder:
   ```bash
   cd online-placement-portal-frontend
   ```

3. **Install Dependencies:**
   ```bash
   npm install
   ```

4. **Start the Development Server:**
   ```bash
   npm run dev
   ```

5. **View the App:**
   Open your browser and navigate to the local URL provided in the terminal (usually `http://localhost:5173`).

## 📜 Available Scripts

In the project directory, you can run:

- `npm run dev`: Starts the Vite development server with hot-module replacement.
- `npm run build`: Builds the app for production to the `dist` folder.
- `npm run preview`: Locally preview the production build.

## 🔮 Project Status & Future Scope

This repository currently serves as a **frontend-only prototype**. 

* **Mock Data:** Data is currently mocked using React state and local arrays for demonstration purposes.
* **Next Steps:** Future updates will involve backend API integration, database connectivity, real authentication, and the addition of Recruiter and TPO (Training & Placement Officer) portals.
