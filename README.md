# Online Placement Portal — Frontend

A professional student-facing frontend prototype for an Online Placement Portal.

- Primary: #1D4ED8

- Secondary: #2563EB
- Accent: #0EA5E9

- Surface: #FFFFFF
- Text: #0F172A
- Muted: #64748B
- Border: #E2E8F0
- Success: #16A34A
- Warning: #F59E0B
- Error: #DC2626

## Included screens
- Student Dashboard
- Find Jobs
- My Applications
- Interviews
- Resume
- Notifications
- My Profile
- Settings

## Run
1. Install Node.js 18+.
2. Extract this ZIP.
3. Open a terminal in the project folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL shown by Vite.

This is a frontend-only prototype. Data is currently mocked in React state and local arrays. Backend authentication, database, recruiter portal, TPO/admin portal, and real application submission APIs can be added next.
